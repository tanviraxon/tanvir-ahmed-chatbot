# TANVIR AI v3.0.0

- Rebranded the project from TANVIR THE AI to TANVIR AI.
- Removed the old tanvir Telegram identity and added @tanvirmunshi.
- Added branded dashboard, logo and banner.
- Added working /start, /help, /menu, /commands, /about, /credits, /owner, /info, /ping, /status, /alive and /clear commands.

- Added /clear to erase a chat's short-term memory.
- Improved system prompt and response behavior.
- Updated package metadata and Render service naming.
- Kept WhatsApp pairing, auto-reconnect, image generation and Render self-ping functionality.
